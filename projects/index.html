ML Security

Context-Aware Detection for Indirect Prompt Injection

Built a lightweight sentence-level classifier for malicious instruction detection in LLM-agent tool outputs. The system combines target-sentence embeddings with query and surrounding-context information, then explores adversarial training through feature-space perturbations and LLM paraphrase attacks.
