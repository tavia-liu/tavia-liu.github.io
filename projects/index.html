Bimanual Multi-Agent Robot Learning Benchmark

Code

Built a bimanual multi-agent manipulation task in ManiSkill and evaluated it alongside two existing ManiSkill tasks. I trained RL baselines from scratch, including PPO, MAPPO, HAPPO, and SAC, to compare how single-agent and multi-agent policies handle coordination, handoff, and control in shared robotic scenes.

National Archives Immigrant Database Platform

Website / Code

Built a database-backed research platform for historical immigrant records, with spreadsheet ingestion, data normalization, relational models, custom admin filters, demographic search, and API-ready infrastructure for archival research. The project turns messy source spreadsheets into a searchable system for migration history and digital humanities work.

Life In Weeks Wallpaper

Public web project

Code

Designed and shipped a small visual web project that turns the scale of a human life into a weekly calendar. It reflects the same design habit I bring to research tools: make abstract systems visible, navigable, and emotionally legible.
