Bimanual Multi-Agent Robot Learning Benchmark

Blog / Code

I built a bimanual multi-agent manipulation task in ManiSkill and trained RL baselines from scratch. The work compares single-agent and multi-agent policies on coordination behavior across my task and two existing ManiSkill tasks.

National Archives Immigrant Database Platform

Website / Code

I built a public research platform for historical immigrant records from the National Archives. The system turns messy spreadsheets into searchable records so researchers can find passenger histories without redoing spreadsheet cleanup.
