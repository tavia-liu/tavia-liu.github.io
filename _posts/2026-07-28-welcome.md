Three public shelves:

- **Research**: projects, papers, open questions.
- **Blog**: essays.
- **TILs**: logs, fragments, things worth remembering.

A note starts as Markdown. Rough notes stay local.

## Private

Anything committed to a public GitHub Pages repository should be treated as public source. Private notes should stay in `_private/` or use the `.private.md` suffix so they remain local and ignored by Git.
